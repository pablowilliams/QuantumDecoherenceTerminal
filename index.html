    How the notebook works

    The simplified model, repeatability contract, and benchmark limits.

    Deterministic browser model

    Calculation

    Each device profile contains a synthetic index, drift, and dispersion. A seeded lognormal path generator produces comparison ranges. The Bloch, decay, and circuit-depth panels are deterministic teaching visualisations rather than a hardware simulator.

    Reproducibility

    The profiles are committed with the source. Holding the device, horizon, path count, and seed constant produces the same output.

    Limits

    • No vendor calibration endpoint or experimental run data is connected.
    • The aggregate index is not an industry-standard hardware score.
    • The model does not solve a Lindblad master equation.
    • No vendor ranking, empirical backtest, or performance claim is made.
